# Quack 디자인 가이드

화면은 `src/main/resources/static/index.html` 하나다. **값의 기준은 그 파일의 `:root` CSS 변수**이고, 이 문서에는 이름과 쓰임새만 적는다. 값을 여기 옮겨 적지 말 것(둘이 어긋난다).

## 방향
- **글래스모피즘**. 은은한 그라데이션 벽(`--wall`) 위에 반투명 블러 패널이 떠 있다.
- 레퍼런스는 code.xr의 "Glassy Dashboard V5" 릴스다. 둥근 패널, pill 버튼, 흰 텍스트, 파란 포인트.
- 다크 모드가 기본 인상(네이비 + 파랑·보라·청록 빛 번짐)이고, 라이트는 파랑·흰색 톤이다. 둘 다 `prefers-color-scheme`로 자동 전환된다.
- 폰트는 Wanted Sans 하나. 코드와 이슈 키(`QK-12`)만 `ui-monospace`.

## 토큰
| 변수 | 쓰임 |
|---|---|
| `--wall` | `body` 배경. 그라데이션 3개 + 바탕색 |
| `--glass` | 바깥 패널 배경 (사이드바, 보드 컬럼, 문서, 입력창 안쪽) |
| `--glass-hi` | 패널 안의 요소 배경 (카드, 검색창, 선택된 메뉴, 코드 블록, 다이얼로그) |
| `--hover` | 호버, 인라인 코드 배경 |
| `--line` | 유리 가장자리 1px 테두리 |
| `--blur` | `backdrop-filter` 값 |
| `--shadow` | 패널 그림자, 카드 호버 |
| `--text`, `--muted` | 본문, 보조 텍스트 |
| `--accent`, `--on-accent` | 주 버튼, 포커스 테두리, 링크, 인용 막대, 드래그 대상 |
| `--todo`, `--doing`, `--done` | 보드 컬럼 점 |
| `--high`, `--mid`, `--low` | 우선순위 점. `--high`는 삭제 버튼에도 쓴다 |

새 색이 필요하면 `:root`와 다크 블록 **둘 다**에 변수를 추가하고 이 표에 한 줄 적는다. 하드코딩 금지(마스코트 SVG와 `dialog::backdrop`만 예외).

## 모양 규칙
| 요소 | 반경 | 비고 |
|---|---|---|
| 바깥 패널 (사이드바, 보드 컬럼) | 20px | |
| 문서, 다이얼로그 | 24px | |
| 카드, 텍스트 영역, 코드 블록 | 14px | |
| 사이드바 링크 | 12px | |
| 버튼, 검색창, select | 999px (pill) | |

- 간격: `body`는 패딩과 갭 모두 12px, 메인은 16px 24px, 문서 안쪽은 24px 40px.
- 움직임: 카드 호버 시 `translateY(-2px)`, 마스코트 `bob`. 둘 다 짧게, `prefers-reduced-motion`이면 마스코트를 멈춘다.

## 컴포넌트 만드는 법
- **바깥 패널**: `#side, section, #page, dialog` 공용 규칙에 선택자를 추가한다. 배경, 테두리, 그림자, 블러가 한 번에 붙는다.
- **안쪽 요소**: `background: var(--glass-hi); border: 1px solid var(--line)`만 쓴다. **`backdrop-filter`를 겹쳐 걸지 않는다.** 부모가 이미 backdrop root라서 안쪽 블러는 부모 안만 흐리게 하고 비용만 든다.
- **버튼**: 기본은 투명 pill(호버 시 `--hover`). 화면당 주 동작 하나만 `class="primary"`.
- **입력창**: `--glass-hi` 배경 + `--line` 테두리, 포커스 때 `--accent` 테두리.
- **빈 상태**: 직접 그리지 말고 `hey(mood, 대사, size)`를 쓴다.
- **이슈 문서**: 같은 다이얼로그의 `사람용 요약`·`에이전트 문서` 버튼으로 전환한다. 선택 상태는 `aria-pressed`와 `--hover` 배경으로 표시한다. 문서별 입력 내용은 전환해도 보존하며 미리보기는 선택된 문서에 적용한다.
- **이슈 저장**: 요청 중에는 폼 컨트롤을 비활성화하고 저장 성공 후 창을 닫는다. 실패 시 초안을 유지하고 다시 활성화한다. 변경이 있는 창의 취소·Esc·화면 이동은 확인한다.
- **홈**: `#home`은 기본 진입 화면이다. 소개와 명시된 사용 예시를 한 유리 패널에 두고, 보드·문서·에이전트 가이드 진입 카드는 안쪽 스타일만 사용한다. 예시를 실제 데이터나 사용 통계처럼 표시하지 않는다. 주 동작은 보드 열기다. 마스코트는 기존 `proud` SVG다.
- **가이드**: `#guide`(사람용)·`#guide/agent`(에이전트용)에서 `static/*-guide.md`를 정화해 표시한다. 원본 다운로드와 선택 상태(`aria-current`)를 제공한다. 사용자 DB에 가이드를 자동 등록하지 않는다.
- **작은 화면**: 1000px 아래에서는 홈 소개와 예시를 한 열로 배치하고, 680px 아래에서는 사이드바를 위로 올린다. 새 색·블러 토큰 없이 기존 라이트/다크 토큰을 사용한다.

## 마스코트
`mascot(mood, size)`가 기본 SVG 마스코트를 만든다. 칸쵸메 팬아트라 개인용으로만 쓴다. 사용자 요청으로 이미지 세트 대신 기존 SVG의 네 표정을 다시 사용한다.

| mood | 언제 | 대사 예 |
|---|---|---|
| `idle` | 기본, 아무것도 안 고름 | "문서를 골라라! 아니면 + 로 새로 만들든가!" |
| `proud` | 좋은 빈 상태 (할 일 0개) | "할 일이 없다! 역시 나야!" |
| `shock` | 못 찾음, 예상 밖 | "꽥?! 없는데…? 다른 말로 찾아봐!" |
| `cry` | 아쉬운 빈 상태, 실패 | "아직 끝낸 게 하나도 없어… 흑" |

- 대사는 반말이고, 허세 부리다 투덜대는 톤이다. 두 줄 이내로 쓰고, 줄바꿈은 `<br>`로 한다.
- 사이드바 로고와 파비콘도 `mascot('idle')`의 SVG를 사용한다. 이전 PNG 세트는 Git 이력에 남아 있다.

- `backdrop-filter` 중첩
- 새 폰트, 아이콘 폰트, CSS 프레임워크 추가 (아이콘이 필요하면 인라인 SVG)
- 라이트 또는 다크 한쪽만 확인하고 끝내기
