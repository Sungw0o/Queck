# 처음 쓰는 Quack

해야 할 일과 오래 남길 지식을 한곳에 모으는, 나 혼자 쓰는 로컬 작업 공간입니다. 작게 기록하고 필요할 때 다시 꺼내 보세요.

## 1. 첫 작업을 만들어 보세요

1. [보드 열기](#board)에서 **새 이슈**를 누릅니다.
2. 제목에는 해야 할 일을 한 문장으로 적습니다. 예: “토큰 재발급 처리 추가”.
3. **사람용 요약**에 목적과 완료 조건을 짧게 적고 저장합니다.
4. 시작하면 카드를 **진행 중**, 끝나면 **완료**로 옮깁니다.

이슈마다 `QK-12` 같은 번호가 붙습니다. 카드를 누르면 다시 열어 수정할 수 있습니다. 우선순위는 높음·보통·낮음 중에서 고릅니다.

## 2. 이슈 하나에 문서는 두 개입니다

| 문서 | 누가 읽나요? | 무엇을 적나요? |
|---|---|---|
| 사람용 요약 | 빠르게 상황을 파악할 나 | 목적, 완료 조건, 현재 결과 |
| 에이전트 문서 | 다음 작업을 이어받을 AI 또는 나 | 결정과 근거, 진행 상황, 검증, 막힌 점, 다음 작업, 출처 |

**사람용 요약 예시**

```text
목적: 토큰이 만료돼도 사용자가 하던 일을 계속할 수 있게 한다.
완료 조건: 재발급에 성공하면 원래 요청을 한 번 다시 보낸다.
현재: 구현 완료, 만료 경계 테스트 진행 중.
```

두 문서 버튼을 눌러 전환해도 작성 내용은 유지됩니다. **미리보기**는 현재 선택한 문서를 보여 주며, 마지막에 **저장**을 누르면 변경한 내용을 함께 저장합니다. 에이전트 문서는 필요할 때만 작성하면 됩니다.

저장에 실패하면 창을 닫지 않고 초안을 유지합니다. 작성 중 취소·Esc·화면 이동을 시도하면 버릴지 확인합니다. 다만 초안이 디스크에 자동 저장되는 것은 아니므로, 브라우저를 강제로 종료하면 복구할 수 없습니다.

## 3. 오래 남길 지식은 문서에 적으세요

1. 사이드바 **문서** 옆의 `+` 버튼을 누릅니다.
2. 제목과 내용을 적고 **저장** 또는 **Ctrl+S**를 누릅니다.
3. 문서를 열고 **하위 페이지**를 누르면 그 아래에 새 문서를 만들 수 있습니다.

문서는 마크다운을 지원합니다.

```markdown
## 토큰 재발급 메모
- 재발급 성공: 원래 요청 재시도
- 재발급 실패: 다시 로그인

관련 작업: QK-12
```

본문에 적은 `QK-숫자`는 해당 이슈를 여는 링크가 됩니다. 코드 블록·인라인 코드·이미 있는 링크 안의 번호는 그대로 둡니다. 문서는 **편집** 버튼이나 본문 더블클릭으로 수정합니다.

페이지를 삭제하면 **하위 페이지도 함께 삭제**됩니다. 앱에는 휴지통이 없으므로 삭제 전에 내용을 확인하세요.

## 4. 필요한 기록을 다시 찾으세요

사이드바 검색창에 짧은 단어를 넣거나 `/` 키를 누릅니다. 제목·사람용 요약·에이전트 문서·위키 본문을 함께 검색합니다.

- “로그인을”보다 `로그인`처럼 짧게 찾습니다.
- 결과가 부족하면 같은 뜻의 다른 단어로 다시 찾습니다.
- **에이전트 문서** 표시가 있는 결과를 누르면 해당 문서를 선택한 이슈 창이 열립니다.

검색은 키워드 방식입니다. 문장의 의미나 동의어를 자동으로 이해하는 검색은 아직 없습니다.

## 5. 연결된 AI에게 원문과 출처를 읽게 하세요

Claude 또는 Codex에 Quack MCP가 연결돼 있다면 이렇게 요청할 수 있습니다.

> Quack에서 토큰 재발급 관련 기록을 찾고, 에이전트 문서까지 읽어서 현재 상태와 다음 작업을 출처와 함께 알려줘.

자주 하는 정리는 Claude Code에서 `/mcp__quack__organize_source`(원본 정리), `/mcp__quack__import_notion`(Notion 가져오기), `/mcp__quack__github_retro`(GitHub 회고)로 바로 부를 수 있습니다.

AI는 Quack에서 **검색 → 원문 조회 → 출처가 있는 답변** 순서로 기록을 사용합니다. Quack 화면 안에 채팅창은 없으며, 앱이 직접 AI를 호출하거나 문서를 자동 요약하지 않습니다. 연결과 인수인계 방법은 [에이전트 가이드](#guide/agent)에 있습니다.

## 6. 원본을 모으고 지식 위키로 정리하세요

사이드바의 **지식 위키**를 엽니다.

1. **원본 자료 등록**에서 제목·원문과 선택적인 출처 URL을 넣습니다. .md/.txt 파일도 읽을 수 있습니다. URL 본문을 자동 수집하지는 않습니다.
2. 같은 내용의 자료는 중복 생성하지 않고 기존 자료를 엽니다. 같은 URL인데 본문이 다르면 기존 자료를 먼저 검토하도록 알려 줍니다.
3. 자료의 **에이전트 정리 요청 복사**를 누르고, Quack MCP가 연결된 Claude/Codex에 붙여 넣습니다. 에이전트가 원문과 기존 지식을 읽고 출처를 연결해 정리합니다.
4. 직접 정리하려면 **위키 발행**에서 본문·읽은 원본·변경 요약을 적습니다. 본문에도 `[원본](#docs/번호)` 링크를 남기면 읽기 쉽습니다.
5. 지식 색인에서 정리 결과를 읽습니다. 문서 아래에 출처·관련 문서·역방향 연결이 표시됩니다. **출처와 발행**에서 다시 정리할 수 있습니다.

출처가 바뀌거나 위키를 일반 편집·복원하면 **출처 재검토 필요**가 표시됩니다. 정리한 사람이 새 원문을 읽고 다시 발행해야 사라집니다. **출처 버전 일치**는 인용한 버전이 같다는 뜻이며 내용의 사실성을 보증하지 않습니다. 점검은 출처 누락·오래된 버전·깨진 링크·다른 문서의 연결이 없는 위키를 알려 줍니다.

완료 이슈를 열고 **위키로 남기기**를 누르면 두 문서가 원본 자료와 위키로 보존됩니다. 자동 요약은 아니며, 나중에 이슈를 수정해도 이 기록은 자동 갱신되지 않습니다. 다시 누르면 기존 위키를 엽니다.

## 7. 충돌과 변경 이력

다른 창이나 에이전트가 먼저 저장하면 오래된 저장을 막습니다. **내 초안**과 **서버의 최신 내용**을 비교하고 필요한 초안을 복사한 다음 최신 내용을 열어 합쳐 주세요. 자동 병합이나 무조건 덮어쓰기는 하지 않습니다.

문서의 **변경 이력**, 이슈의 **이력**에서 과거 버전을 읽고 복원할 수 있습니다. 복원은 새 버전을 만들므로 현재 내용도 이력에 남습니다. 위키의 과거 연결 관계와 상위 문서 관계는 복원하지 않습니다. 이력은 기능 설치 이후부터 저장되며, 문서를 삭제하면 이력·발행 로그도 함께 사라집니다. 인용 중인 원본은 삭제가 거부됩니다.

## 8. 마크다운 가져오기와 내보내기

지식 위키 화면의 **마크다운 가져오기**로 일반 메모를 추가합니다. 원문으로 보존할 자료는 **원본 자료 등록**을 사용하세요. 문서의 **마크다운 받기**는 한 문서를, **전체 내보내기**는 이슈 두 문서와 페이지를 Markdown ZIP으로 받습니다. ZIP 안에서는 내부 링크가 문서 파일을 가리킵니다.

파일 가져오기는 UTF-8 .md/.txt만 지원합니다. ZIP·PDF 추출·웹 자동 수집은 지원하지 않습니다. Markdown 내보내기는 전체 DB 복원용이 아니므로 계속 `quack backup`을 사용하세요.

## 자주 쓰는 단축키

| 키 | 동작 |
|---|---|
| `/` | 검색창으로 이동 |
| `n` | 새 이슈. 문서 화면에서는 새 문서 |
| `Ctrl+S` | 편집 중인 위키 문서 저장 |
| `Esc` | 이슈 창 닫기 또는 문서 편집 취소. 변경이 있으면 확인 |

입력칸에 글을 쓰고 있을 때 `/`나 `n`은 그대로 입력됩니다.

## 기록을 오래 보관하려면

프로젝트 폴더의 터미널에서 `quack backup`을 실행하면 `backups/`에 DB 백업이 생깁니다. PowerShell에서는 `.\quack backup`입니다. Docker가 실행 중이어야 합니다.

매일 자동 백업 등록은 `quack schedule`이며, 결과는 `backups/backup.log`에서 확인합니다. 복원은 빈 DB에서 진행해야 하므로 기존 데이터가 있다면 먼저 확인하세요.
